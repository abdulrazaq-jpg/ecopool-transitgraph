# EcoPool / TransitGraph

## Overview

EcoPool / TransitGraph is a MERN stack web application designed to coordinate shared mobility within a campus community.

The application helps students register their journeys, identifies compatible trips, and supports drivers or administrators in managing ride requests.

## Problem Statement

Students and faculty travelling to similar destinations at similar times may use separate vehicles. EcoPool / TransitGraph aims to facilitate shared travel by helping users identify compatible journeys and coordinate ride requests.

## Technology Stack

* **Frontend:** React
* **Backend:** Node.js and Express.js
* **Database:** MongoDB

## Core Workflow

1. Students register their journeys.
2. The application identifies and groups compatible trips.
3. Drivers or administrators manage ride requests.

## Project Goals

* Build a functional full-stack web application.
* Apply software engineering principles throughout development.
* Design structured database models and REST APIs.
* Provide a usable, responsive interface.
* Support the United Nations Sustainable Development Goal 11: Sustainable Cities and Communities.
